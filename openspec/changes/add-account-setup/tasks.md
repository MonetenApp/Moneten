# Tasks

One task per requirement of the spec. A task is checked only when a test or a check in the running app shows the behavior. "Debug app check" is the run of a debug build against `scripts/fake-fints-helper.sh` that pull request #85 records.

## 1. Requirements

- [x] 1.1 Assistant with three steps. Verified by the debug app check: "Add Account..." opens the bank step, "Next" leads to the login data and the accounts, and "Back" returns with the entry kept. The debug app check of issue #108 shows "Step 1 of 3: Bank" and "Step 2 of 3: Login data", the focus in the login name field after "Next", no focus after "Back", so a typed "oops" leaves the chosen bank as it was, and the login name kept after "Back" and "Next".
- [x] 1.2 Find the bank by name, IBAN, or Bankleitzahl. Verified by BankAccessTests "An IBAN with spaces and lower case letters names its Bankleitzahl..." and the debug app check, which shows "Musterbank" for "de02 1203 0000 0000 2020 51". The search by name is verified by BankDirectoryTests (parts of names, umlauts and accents, several words, ranking, FinTS banks first, short names such as "DKB", the start of a Bankleitzahl, no match), by BankLookupTests "A name lists the banks that match, and the chosen bank takes the place of the entry" and "The helper sends the bank directory once...", by FinTSConnectorTests "Reads the bank directory of the helper", by FinTSHelper self-test "bank directory with every bank", and by the debug app check of issue #108: "consors" lists both Consorsbank rows with place and Bankleitzahl, "Next" chooses Nürnberg 76030080, and "munster" finds "Sparkasse Münsterland Muster". Skatbank and Ordensbank are found by their brands and shown as "VR-Bank Altenburger Land / Skatbank" and "Wiesbadener Volksbank / Ordensbank", and "apobank" finds 30060601 first, verified by CooperativeBankTests "Skatbank and Ordensbank are found by their brands..." (#230).
- [x] 1.3 Check the IBAN before any connection. Verified by BankAccessTests "A wrong entry names the failed check before any bank is contacted".
- [ ] 1.4 Check the Bankleitzahl. Built in part: an unknown Bankleitzahl says that it is invalid, verified by BankLookupTests "A wrong entry shows its error only when asked to...". The bank directory marks no outdated Bankleitzahl, so the app cannot say that one is outdated. For the entry of a merged bank it shows a note and goes on (1.22).

- [x] 1.6 Other services. - [ ] 1.7 Choose the access method. Not built until a second method exists (E6).
- [ ] 1.8 Explain why a bank cannot be added. Built in part: a bank without a FinTS address names the bank, says that it does not provide a FinTS/HBCI server and that an extension can add support, and stays on the first step, verified by BankLookupTests "A wrong entry shows its error only when asked to, and a bank without a FinTS address cannot be used" and the debug app check. The message does not name the subscription, which the change add-aggregator-subscription builds.
- [ ] 1.9 Ask for the login data in the words of the bank. Built in part: the label and a help line of the login name for Consorsbank, DKB, comdirect, ING, and the savings banks, from a public page of each bank, matched by the Bankleitzahlen that a page of the bank names, verified by LoginHintTests, including "DAB BNP Paribas shares the FinTS server of Consorsbank and gets no hint...", and by the debug app check of issue #108, which shows "Account number + 001" for Consorsbank and "Login name or Legitimations-ID" for a savings bank. A cooperative bank on the FinTS servers of Atruvia asks for "VR-NetKey or alias", and a Sparda-Bank and the Südtiroler Sparkasse on the same servers do not, verified by CooperativeBankTests "A bank on the servers of Atruvia asks for the VR-NetKey or alias..." and by the debug app check of #230 with the made-up Volksbank Musterstadt of `scripts/fake-fints-helper.sh`, which shows the label, the help line, and the link (#230). Every other bank asks for "User ID". These banks ask to leave the customer ID empty, so the step has no customer ID field.
- [ ] 1.10 Check the format of login fields. Built in part (#230): on a FinTS server of Atruvia a login name of more than 30 characters fails before any connection, verified by CooperativeBankTests "A login name of more than 30 characters fails before any connection...", and a PIN of 6 characters gets its own message when the bank parameters require more, in the login step and in the PIN sheet, verified by PINRulesTests "A PIN of the length that the server refuses...", SetupSessionTests "A six character PIN for a server that refuses it...", and FinTSConnectorTests "A cooperative bank on a server of Atruvia refuses a six character PIN...". The bank directory and the extensions declare no other formats yet.
- [ ] 1.11 Show what the bank requires before the first login. Built in part: the help button of the first step says that a credit card is added with the Bankleitzahl of the bank that issued it, or with "Look for New Accounts..." on the giro account, verified by the debug app check of PR #271. The bank directory holds no notes of the banks. The app has one note: the login step of a savings bank says to log in with the login name and the PIN of the online banking and to set up a TAN method such as pushTAN or chipTAN there first (#240), verified by SavingsBankTests "The login step of a savings bank says to use the login of the online banking and to set up a TAN method there first" and by the debug app check in light and dark.
- [x] 1.12 Report a failed login without leaving the assistant.
