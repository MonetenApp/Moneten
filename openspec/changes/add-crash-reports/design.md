## Ownership

[ADR 0002](../../../docs/decisions/0002-local-first-no-server.md) forbids telemetry. Domain accepts a plain crash diagnostic struct and builds a report without I/O. Only numeric versions, exception and signal numbers, known binary names, valid binary UUIDs, and offsets can enter its text. Unknown binary names become "Other". Binary UUIDs identify release artifacts, never a device, installation, or database.

App maps MXCrashDiagnostic to the struct. It reads only the crashed thread of the stack tree. Objective-C reasons, termination reasons, memory details, process identifiers, and other metadata never enter the report builder.

Storage uses AES-GCM and a dedicated random key protected by the existing Keychain implementation. This works before the database unlocks and needs no schema migration. One encrypted state holds the newest payload end time or decided fallback time, the pending report, the launch start and versions, and the time of a declined short report. Optional launch fields let existing state survive the update. A first launch records its start without inferring a crash. Each later launch first checks files newer than the saved start and older than this launch, then saves the new start. A decision removes the diagnostic but retains its time. Completing a short-report decision advances that saved time, so diagnostics from any earlier decided crash cannot ask again. MetricKit exposes payload times, not individual crash times. Within the newest payload the last crash is kept.

App shows the sheet above the root view, including while the database is locked. A cut report stays after opening GitHub until Copy Report or Don't Report. A failed deletion leaves it available and shows an error. Opening a browser is an explicit action; submitting the issue remains the user's choice.

Domain constructs the GitHub URL with template bug-report.yml and fields version and macos. The report goes only into the form's expected field. The encoded URL stays below 8,000 characters. It truncates only between frame lines and appends a notice. The pasteboard always gets the full report.

Maintainers use scripts/symbolicate-crash.sh with the matching dSYMs. The script matches binary UUIDs and adds each offset to the Mach-O text segment address before calling atos. This change records dSYM retention in the open release tasks and does not implement uploading.

App lists only Moneten-*.ips and Moneten*.crash in the user's Library/Logs/DiagnosticReports directory and reads their modification dates. It never opens a system report. Storage makes the fallback decision from those names and dates and the saved launch state. The short report includes only saved versions, the newest matching date in UTC, and "No details were available." A MetricKit payload whose time interval contains that date replaces the short report unless it was declined. Payloads expose intervals rather than individual crash times, so that interval is the available correlation signal. No quit marker is used. The existing main-window dialog observer also observes pending crash reports.
