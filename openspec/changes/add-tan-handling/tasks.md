# Tasks

One task per requirement of the spec. A task is checked only when a test or a check in the running app shows the behavior. "Debug app check" is the run of a debug build against `scripts/fake-fints-helper.sh` and the requests of `SyncDemo`, which pull request #86 records with light and dark screenshots. Every scenario also needs the check with real banks of task 3.1 of add-account-refresh.

- [x] 1.50 Name the Security App of Oberbank among the TAN methods (#236). When the FinTS server of the Bankleitzahl 70120700 offers no app, the choice of the TAN method shows "Oberbank Security App" as a method that cannot be chosen, with the reason that Oberbank offers it only for its internet banking and not for finance software. A method is an app by the bank parameters, or by a word of its name that is or ends with "app", with or without "tan" after it, so "SecurityApp" and "appTAN" count and "Appsecure" does not. hbci4java takes a single method without a choice, so the helper sends with every challenge the methods that the bank allows, also a single one, and the TAN dialog of such a server gives the reason as its note, also after a choice. An approval in an app, a server that offers an app, and another bank on the same FinTS server of Bank-Verlag get neither. Verified by OberbankTests "Oberbank shows its Security App as a method that cannot be chosen...", "Oberbank shows only the methods of its FinTS server when one of them is an app...", "Oberbank counts a method as an app by a word that is or ends with \"app\"...", "When the FinTS server of Oberbank offers only smsTAN...", "The TAN dialog of Oberbank names the Security App after the choice of a method...", "The TAN dialog of another bank on the FinTS server of Bank-Verlag says nothing about the Security App", and "Another bank on the FinTS server of Bank-Verlag shows only the methods of the server", and by the FinTSHelper self-test "a TAN request of the single method that the bank allows names it".
